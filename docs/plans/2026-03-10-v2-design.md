## Execution Strategy

1. Create v2 branch from v1
2. Reorganize existing scripts into fundamentals/ sub-folders
3. Update README, animations paths, CLAUDE.md
4. Build scripts by category (8 at a time, parallel agents)
5. Generate GIFs alongside each batch (judge system: 3 variants, pick best)
6. Run GIF audit workflow per batch
7. Update README with expanded grid
8. Final push

## Constraints (same as v1)

- Python 3.10+ stdlib only (no pip installs)
- Single-file, self-contained scripts
- Runs standalone in seconds on CPU
- Heavy inline comments
- Script template: docstring, constants, implementation, demo, entry point
- GIFs: 800x550, 36 frames, 90ms, Pillow only
